# Latest version: `aerynOS 2026.08`

:::caution
Our alpha `lichen` installer intentionally does not support dual boot scenarios at this stage. 
:::

We provide a live environment with the [GNOME Desktop](https://www.gnome.org/) as a vehicle for our alpha `lichen` live installer which is able to install all of our Desktop Environments and Wayland Compositor environments. It will always pull the latest packages from our repository at the time of installation.

We advise using [Etcher](https://etcher.balena.io/), [KDE ISO Image Writer](https://apps.kde.org/en-gb/isoimagewriter/) or `dd` to write the aerynOS ISO to a separate USB stick. Other tools may work but are not guaranteed. [MultiOS-USB](https://github.com/Mexit/MultiOS-USB) is also known to work for writing multiple ISOs to the same usb stick.

For a full guide to installing aerynOS including prerequisite requirements, downloading and installing the ISO to a USB stick, please refer to our [documentation](/users/getting-started/).
