## A different approach to system updates

A big problem with traditional package managers is that they apply updates incrementally, so if the update fails part part way through, you can be left with a partially updated and broken system. aerynOS takes the atomic approach to package management. `moss` downloads and prepares the package update in one go and then atomically switches over to the new system state. If an update were to fail, the transaction would not complete and your system would be left untouched. We do this without immutable system images that require reboots for every system update.

Things can still go wrong, so we keep all previous system states available to users to allow for roll backs. Via `moss`, you can roll back to any earlier system state. You can also roll back to one of the previous 5 system states at boot time. This provides an extra protection layer in case anything goes wrong.   <BoxSectionBox icon="fa6-solid:box-archive" title="moss" subTitle="System and Package Management">
    [`moss`](/tooling/moss) is our package and system state manager. We use a transaction-based approach that allows for new system states (or "transactions") to be constructed and then activated atomically reducing the risk of broken updates. 
    
    Previous system states remain available to the user so they can rollback as needed.
  </BoxSectionBox>
  <BoxSectionBox icon="fa6-solid:hammer" title="boulder" subTitle="Package Build System">
      [`boulder`](/tooling/boulder) is our tool for building packages for aerynOS from yaml based recipe definitions. 
      
      When combined with our build infrastructure, it allows us to package up open source software and publish it to our repositories.
  </BoxSectionBox>
  <BoxSectionBox icon="fa6-solid:hard-drive" title="blsforme" subTitle="Boot Management">
    [`blsforme`](https://github.com/aerynOS/blsforme) is our custom Boot Loader Specification compliant management tool.
    
    It helps manage `ESP` and `XBOOTLDR` partitions and generally manage booting aerynOS systems. 
  </BoxSectionBox>

## Built in the open

aerynOS is an open source project that thrives based on community effort. We are developing the distribution, our Rust based tooling and package recipes in the open, primarily over at GitHub. We share regular updates on our blog and communicate via Zulip and Discourse. We welcome people who want to test the distribution, report issues, improve documentation or contribute code, artwork, or package recipes.
