## Project viability

aerynOS has been designed with scalability and efficient use of resources in mind. During the second half of 2025, the team conducted an audit and made changes that both reduced running costs but also improved capability. Key to this was the team's approach to prioritise the use of internal resources wherever possible (such as ermo's personal build servers), and then only paying 3rd parties for the servers / solutions we can't cost-efficiently deliver in-house.

Sponsorship coming in through Ko-fi adequately offset all project costs meaning the project is self sustaining.

## How will funding help the project

The primary way to help the project at this stage is through further sponsorship. Your support will help us continue to improve and expand the project, as we work towards stable releases.

At a high level, the team would like to build up an amount of savings to cover project running costs in case of emergency. Outside of this, we would also like to invest in additional build servers to support multi-arch and psABI builds.

Finally, as we scale out into a more serious project, we would eventually like to be in a position where we can utilise funds for defined projects such as branding, website design or anything else that may come up.
